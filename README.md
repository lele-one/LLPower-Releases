## 中文

LLPower 是一款免费的 Android 电源监控软件，实时读取功率、温度、电压与电流，自动记录每次充放电，并使用机器学习算法预测充电与续航时间。数据只保存在设备本地，不联网、无广告。

### 主要功能

- 实时监测功率、温度、电压与电流

- 使用机器学习预测充满时间与续航时间
- 支持虚拟电压与双电芯修正

## English

LLPower is a free Android power monitoring app that reads power, temperature, voltage, and current in real time, automatically records charging and discharging sessions, and uses machine learning to estimate charging and battery endurance time. All data stays on your device. The app has no network permission and no ads.

### Key features

- Real-time power, temperature, voltage, and current monitoring
- Automatic charging and discharging records
- Machine-learning estimates for time to full and battery endurance
- Virtual voltage and dual-cell correction
- Home-screen widgets and Dynamic Island-style live notifications
- Customizable themes and wallpapers
- Local-only data storage with no network permission
